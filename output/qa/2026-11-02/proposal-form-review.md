## 표시 확인과 저장

- 출력: [DOC](../../documents/리스크렌즈_상세기획서_작성본.doc), [DOCX](../../documents/리스크렌즈_상세기획서_작성본.docx).
- 네이티브 Word의 PDF 저장과 Poppler 렌더를 사용해 DOC 9쪽 전체를 확인했다. 관리형 LibreOffice 런타임이 노출되지 않은 Windows 환경에서 원본 `.doc`를 Word로 직접 편집·렌더했다.
- DOCX를 다시 열어 렌더한 결과도 9쪽이며 페이지별 추출 본문이 DOC와 같다. 서로 다른 픽셀이 있는 4·5·8·9쪽은 따로 열어 확인했으며 미세한 글꼴·이미지 렌더 차이 외에 잘림·겹침·깨진 표는 없다. 나머지 5쪽은 픽셀도 같다.
- 원본 제목과 표 스타일, 숫자·영문 줄바꿈, 그림의 종횡비, 같은 페이지의 그림 설명, 표 머리글·참고 링크를 확인했다. 이미지와 표는 본문 영역 안에 있다.
- 안내문·임시 마커·대체 글리프가 남지 않았고, 원본 해시·페이지 설정·제목 순서·그림 3개·출처 링크·메타데이터 검사를 통과했다.
- PDF와 페이지 PNG는 내부 표시 검사 자료로만 `tmp/proposal-form`에 두었다. 제출용 PDF를 새로 만들었다고 기록하지 않는다.
