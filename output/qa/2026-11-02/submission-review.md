# 공모전 참고자료 확인 기록

- 기준: 2026-11-02, Android 1.2.0, Samsung SM S906N.
- 공개 PDF 7쪽, 심사용 PDF 6쪽, 메일 안내서 6쪽. 총 19쪽을 Poppler로 렌더하여 배치·글꼴·이미지·표·쪽번호·푸터를 확인했다.
- 실제 메일 캡처 두 장은 사용자 원본을 그대로 내부 안내서와 내부용 폴더에 넣었다. 영어 핵심 문장의 발췌와 한국어 설명을 함께 수록했다. 확인하지 않은 메일 헤더·전송 ID는 작성하지 않았다.
- 공개 영상과 심사 영상은 각각 73초, H.264 MP4, 1080×1920, 무음이다. 실기기 조작을 발췌 편집했으며 PDF 화면은 최종 MP4의 해당 시각에서 추출했다.
- 공개용 모든 이미지의 픽셀은 공개 최종 영상 프레임과 일치한다. 심사용 모든 이미지도 해당 심사 영상 프레임과 일치한다. 공개용에 심사 전용 이미지나 첨부 파일이 섞이지 않았는지 검사했다.
- PDF 두 종의 파일 첨부 MP4와 별도 MP4는 SHA-256이 일치한다. 마지막 쪽의 클립 아이콘·파일명·장면별 시간을 확인했다. 첨부를 지원하지 않는 뷰어를 위해 별도 MP4도 동봉했다.
- ZIP은 9개 파일, 약 17.4 MB다. CRC와 내부 모든 파일의 해시를 확인했으며 바탕화면 복사본도 같다. APK·서명 파일·환경파일·인증정보는 포함하지 않았다.
- 실제 종목 차트는 심사용에만 포함한다. 문의 당시 차트 미표시 계획과 이번 보충 시연의 관계를 안내서에서 구분했다. 회신을 차트 항목의 별도 명시 승인으로 표현하지 않았다.
- 이번 심사 촬영은 로컬 template 설명이다. 기본 설명을 실제 LLM 응답으로 표시하지 않았다. 앱·API 코드·계약·공개 운영 종목 차단은 변경하지 않았다.
- 촬영 후 보관된 운영 APK로 다시 설치했다. 설치된 APK의 SHA-256은 보관본과 일치하고 촬영용 8765 USB 전달과 로컬 서버는 종료했다.
- 자료 생성·검사 스크립트 3개의 Ruff 검사와 포맷 검사를 통과했다. 계산 변경이 없어 앱·API 테스트 성공 횟수를 추가하지 않았다.
- 심사 자료·메일 캡처·전체 ZIP은 `.gitignore` 대상이며 로컬에만 보관한다. 주최 측에 제출하거나 공개 게시하지 않았다.
