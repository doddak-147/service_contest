# 핵심 사용자 흐름

## 1. 기본 흐름

1. **목적과 한계 확인**  
   사용자는 투자 추천·미래 예측 서비스가 아니며 과거 데이터가 미래 결과를 보장하지 않는다는 설명을 확인한다. 로그인은 요구하지 않는다.

2. **개인 금융상태 입력**  
   월 소득, 고정지출, 비상자금, 기존 대출, 월 상환액, 투자 예정금액, 자기자본, 투자용 차입금, 연 금리를 입력한다. 단위와 포함 범위를 필드 옆에 표시한다.

3. **개인 금융체력 확인**  
   월 잉여현금, 비상자금 버팀 개월, 차입 비율, 예상 월 이자를 확인한다. 화면은 안전 점수나 투자 가능 여부를 표시하지 않는다.

4. **종목과 분석 기간 선택**  
   종목명 또는 심볼을 검색하고 시장·통화를 확인한다. 데이터 제공자, 조회 기간과 최신 기준일을 표시한다.

5. **종목 과거 위험 확인**  
   기간 수익률, 변동성, MDD와 주요 하락 구간을 확인한다. 각 지표에서 쉬운 정의와 데이터 한계를 펼쳐 볼 수 있다.

6. **개인×종목 결합 분석 확인**  
   선택 종목의 과거 MDD를 사용자의 투자 예정금액에 적용한다. 예상손실, 자기자본·비상자금·생활비 대비 영향, 하락 후 투자자산과 순투자지분을 확인한다.

7. **가격 충격 시나리오 비교**  
   `+20%`, `0%`, `-10%`, `-20%`, `-30%`, `과거 MDD` 여섯 결과를 동일 기준으로 비교한다. 이는 발생 시점이나 확률이 없는 가정임을 명시한다.

8. **결과 Report와 AI 설명 확인**  
   사용자는 계산값, 계산식, 입력 근거, 데이터 기준일을 먼저 확인한다. AI는 그 결과를 쉬운 한국어로 설명하며 새로운 숫자나 투자 행동을 제시하지 않는다.

9. **수정 또는 종료**  
   재무값, 종목, 기간을 수정하면 현재 값으로 다시 계산한다. MVP는 분석 이력을 서버에 저장하지 않는다.

## 2. 화면 흐름

```text
안내
 → 재무 입력 → 금융체력
 → 종목 선택 → 과거 위험
 → 개인×종목 결합 분석
 → 6개 가격 충격 비교
 → Report + AI 설명
```

Report에서는 재무 입력과 종목 선택 화면으로 돌아가는 경로를 제공한다. 수정 후 이전 계산과 AI 설명을 폐기하고 새 계산이 완료된 뒤 설명을 다시 요청한다.

## 3. 오류와 대체 흐름

- **입력 불일치:** `자기자본 + 투자용 차입금`이 투자 예정금액과 다르면 관련 필드에서 수정 방법을 안내한다.
- **0인 분모:** 자기자본, 비상자금, 고정지출이 0이면 관련 비율을 `null`로 받고 화면에는 계산 불가 사유를 표시한다.
- **종목 중복:** 같은 심볼이 여러 시장에 있으면 종목명, 시장, 통화로 다시 선택한다.
- **시세 부족:** 가능한 기간과 제외 지표를 알리고 값을 추정하지 않는다.
- **주가 API 실패:** 재시도를 제공하고 금융체력 및 고정 `+20%`~`-30%` 시나리오는 계속 사용할 수 있게 한다. 과거 MDD와 결합 분석은 비활성화한다.
- **LLM 실패/부적합:** 숫자 Report는 유지하고 검수된 정적 문구를 표시한다.
- **100% 손실:** 회복 필요 상승률을 유한한 숫자로 표시하지 않는다.

## 4. 표현 원칙

- “투자해도 됩니다” 대신 “이 가정의 손실은 자기자본의 72%입니다”라고 표현한다.
- “이 종목은 위험합니다” 대신 기간, 변동성, MDD와 출처를 함께 표시한다.
- “예상 주가” 대신 “가격 충격 가정 후 투자자산”을 사용한다.
- 기간 누적 이자나 부채 변화처럼 MVP가 계산하지 않는 정보를 암시하지 않는다.
