# 기능 확장 진행 기록

작업 기준은 검증·릴리스 통합 버전 `310c002`다. 로그인·DB·서버 분석 이력은 추가하지 않는다. 실제 데이터 기능은 비공개 시연 범위를 유지한다.

1. 월별 현금흐름: Stress Test 소유의 새 `/stress-tests/cash-flow` 계약과 결정론적 계산, 3·6·12개월 그래프·월별 내역. 현금 시작값은 투자 후 별도로 남겨 둔 비상자금이다. 평가손익은 현금에 합산하지 않는다.
2. 생활 충격: 같은 계약에서 소득 감소·고정지출 증가·투자용 금리 상승을 적용 전후 비교한다. 기존 대출 월상환액은 고정한다. 투자용 이자 납부·만기 상환 및 원금 균등분할을 명시적 가정으로 제공한다.
3. 과거 가격·MDD: 원화·달러 기준 변화 그래프와 동일 기간의 고점·저점·회복 표시. 실제 시세와 공개용 가상 그래프를 구분한다. 추가 계약·타입·어댑터·테스트를 함께 갱신한다.
4. 가정 A·B: 실행 중 화면에서만 두 입력·응답을 보관한다. 조건 차이와 현금·이자·평가 결과를 비교하며 적합성 판정을 하지 않는다.
5. 위험 이해 체험: 가상 사례의 선택→정답/오답→계산 근거. 자체 문제는 서버 없이 동작한다. 명시적으로 요청하면 서버가 가상 문제를 만들고 AI는 제목·도입만 구성한다. 실제 시세·계정·서버 풀이 기록은 사용하지 않는다.

## 현재 상태

- 1·2의 계산 API·모바일 화면·가상 사례를 구현했다. 계산·API 13개, A·B를 포함한 화면 5개 테스트를 통과했다. 입력 변경·늦은 응답 무시·큰 글자·무호출 체험을 포함한다.
- 3의 가격 시계열 API·두 통화 곡선·MDD 음영과 표식·공개용 가상 곡선을 구현했다. API·계산 7개 및 그래프·오프라인 화면 테스트를 통과했다. 같은 요청 범위를 재사용하며 그래프 실패는 기존 요약을 지우지 않는다.
- 4의 A·B 보관·조건 차이·현금/이자/평가 비교를 구현했다. 각 슬롯은 계산에 사용한 불변 입력과 응답을 함께 보관하며 화면을 닫으면 삭제된다. 다른 기간끼리 비교하면 기간 차이를 명시한다. 화면 테스트 5개를 통과했다.
- 5는 8개 주제에서 한 번에 5문제를 구성하도록 확장했다. 정답·오답·내 선택을 표시하고 근거를 확인한다. AI는 제목·도입 문구만 구성하며 가상 수치와 정답은 서버가 계산한다. 오프라인 자체 문제도 제공한다. 점수·투자 적합성 판단·기록 저장은 하지 않는다.
- 2026-11-02 운영 release `api-1.2.0-ada4794dbbd6`에 확장 API를 배포했다. 외부 HTTPS에서 현금흐름 산술과 AI 5문제를 확인했으며 실제 시세·가격 그래프·결합 분석의 공개 차단은 유지한다.
- USB 기기 `RFCT328Q92E`에서 디버깅 재승인 후 통합 테스트 4개를 통과했다. 서명된 1.1.0 설치본을 복원하고 운영 HTTPS 연결, 가상 현금흐름·누적 이자·A/B·가격 그래프·이해 체험 화면을 확인했다.

## 자동 검증

2026-11-02 API·검사 스크립트 테스트 164개, 최종 Flutter 테스트 78개, Ruff와 Flutter analyze를 통과했다. 현금흐름의 무소득·무이자·0인 분모·100% 평가손실·만기·반올림과 시세의 결측·중복 날짜를 검증했다. 좁은 화면/큰 글자, 입력 변경 중 늦은 응답 무시, 가정 보관 후 화면 종료, 체험 네 사례 순환도 포함한다. 새 종속성은 추가하지 않았다.

실제 제공자 연결은 로컬 전용 QA API에서 공개 데모 키의 AAPL 요약·시계열 응답 HTTP 200과 관측치 63개를 확인했다. Android 통합 테스트에서도 해당 응답을 받아 원화·달러 그래프가 표시되고 두 첫 관측값이 100인 것을 확인했다. 개인 키·실제 사용자 재무정보는 사용하지 않았다. 전체 종목 지원 검증으로 확대하지 않는다.

`integration_test/feature_expansion_test.dart`의 4개 테스트는 실제 로컬 API의 현금흐름·생활 충격·A/B, 원화/달러 시계열 연결, 가상 3·6·12개월, 이해 체험 네 사례를 검증한다. 2026-11-02 `SM S906N`(Android 16)에서 전부 통과했다. 재실행은 사설 시연 API를 켜고 `adb reverse tcp:8000 tcp:8000`, `flutter test integration_test/feature_expansion_test.dart -d RFCT328Q92E --dart-define=API_BASE_URL=http://127.0.0.1:8000` 순으로 진행한다. 이번 QA는 별도 로컬 포트 8765를 사용했으며 종료 후 서버와 USB 포트 전달을 제거했다.

실기기 캡처 과정에서 A/B 비교까지 스크롤하면 가상 표기가 사라지는 점을 수정했다. 가상 현금흐름 제목과 비교 카드에 표기를 유지한다. 수정 후 해당 화면 테스트 5개와 정적 검사를 재통과했고 다시 빌드한 서명 APK를 덮어 설치해 표기를 확인했다. 공개용 가상 화면만 보관한 캡처는 [QA 기록](QA_REVIEW.md)에 연결했다.

1.1.0(`versionCode=3`) 서명 APK를 생성하고 기존 인증서와 같은 서명을 검증했다. 검토 브랜치는 `feature/foundation-feature-expansion`이며 `main` 병합과 외부 서명 백업은 별도 대기 상태다.

## 1.2.0 보완

- 현금흐름 시연을 먼저 진행하고 `output/demo/RiskLens-cash-flow-walkthrough.mp4`에 약 2분 37초의 가상 조작 영상을 저장했다. 음성은 없으며 실제 시세·개인 재무값은 사용하지 않았다.
- 상환 방식의 가로 넘침, 펼친 입력 영역 첫 줄의 라벨 잘림, 주가·환율 버튼 여백을 보완했다. 입력 제목을 칸 위로 분리하고 선택란의 줄바꿈·높이를 허용했다. 위로 스크롤한 뒤 돌아와도 펼침 상태와 입력값이 유지된다.
- 문제 생성은 API 계약 7절을 따른다. 기존 쉬운 설명의 OpenAI 설정을 재사용한다. Windows 클립보드 잠금에 재시도하며 `start-local-api.ps1 -PasteKeys`는 숨김 입력창에 키를 직접 붙여넣는다.
- 자동 테스트는 API·스크립트 180개, Flutter 81개를 통과했다. 실기기 추가 통합 테스트 3개는 입력 영역·정답/오답·5문제 완료·문제 API 연결을 검증했다. 사용자 로컬 서버에서 실제 OpenAI 응답 `source=llm`, 대체 사유 없음, 5문제를 확인했다. 개인 키는 사용자 터미널에만 입력했다.
- 실제 AI 표시를 요구한 로컬 Android 테스트도 3개 통과했다. 당시 로컬 API 8000번 연결 시험판과 운영 주소용 서명 APK를 각각 생성했다. 이후 클라우드 API를 배포하고 운영 HTTPS 실기기 검사 4종을 통과했다. AI 검사는 한 차례 자체 문제 대체 후 재요청에서 성공했다. 서명 APK 설치·홈 연결·가상 재무 예시의 온라인 계산도 확인했다. 물리적 USB 분리 결과는 사용자 응답 대기 중이며 `main` 병합은 별도 리뷰 대상이다.

## 운영 배포 검증

`deploy/cloud/apply-release.py`는 원본 앱·환경파일을 보존하고 임시 서비스 → 실제 서비스 전환 순서로 검사한다. 배포 도구 테스트 11개는 manifest·해시·경로/링크 거부, 실제 계산 API 대조, 전환 실패 시 복구 호출을 검증했다. 서버의 Python 3.12.3, FastAPI 0.141.1, Pydantic 2.13.5, httpx 0.28.1을 확인했다. 운영 라이브러리를 업그레이드하지 않았다. 실제 사용자 재무값이나 Twelve Data 시세로 배포 검사를 수행하지 않았다.
