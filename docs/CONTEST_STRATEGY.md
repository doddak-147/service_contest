## 2. 사회문제 정의 및 통계 근거

핵심 주장: 차입투자자는 가격 하락과 이자 부담을 동시에 감당해야 하지만 기존 투자 정보만으로 그 충격을 개인 생활 단위에서 이해하기 어렵다.

현재 구현 근거에는 3·6·12개월의 생활 충격·누적 이자·원금 상환·현금 잔액과 가정 A/B 비교, 5문제 위험 이해 체험을 포함한다. 투자 평가손익을 실제 현금 지출과 분리한다. AI는 검증된 설명과 문제 제목·도입을 보조하며 금융 수치·정답은 서버 계산이 확정한다. 개발자 점검과 사용자가 직접 확인한 사실을 사용자 조사나 외부 전문가 검토로 확대하지 않는다.

다음 근거를 조사해 `수치 / 조사 시점 / 조사 대상 / 원문 링크 / 해석의 한계` 형식으로 기록한다.

| 필요한 근거 | 우선 출처 | 상태 |
|---|---|---|
| 국내 차입투자 또는 신용융자 규모와 변화 | 금융감독원, 한국은행, 금융위원회, 거래소 | 조사 필요 |
| 청년층 부채와 원리금 상환 부담 | 한국은행, 통계청, 금융감독원 | 조사 필요 |
| 금융이해력과 생활 속 적용의 배경 | 한국은행·금융감독원 「2024 전국민 금융이해력 조사」 | 공식 게시물과 첨부 HWP 확인. 성인 2,400명, 지식 73.6점·행위 64.7점. 차입투자 피해·앱 효과의 직접 측정은 아님 |
| 과도한 부채가 생활에 미치는 영향 | 공공기관·동료평가 연구 | 조사 필요 |

통계는 서비스 필요성을 설명하는 데만 사용하고 특정 집단이 무조건 위험하다고 단정하지 않는다.

조사 원문: <https://www.bok.or.kr/portal/bbs/B0000502/view.do?menuNo=201265&nttId=10091152> (2025-04-29 게시, 2026-11-02 확인). 소폭 하락이나 지식·행위 점수의 차이만으로 원인 또는 본 서비스의 효과를 단정하지 않는다.

## 3. 기존 서비스 비교

최소 3개 실제 서비스를 직접 사용하거나 공개 자료로 확인한 뒤 아래 표를 채운다.

| 비교 항목 | 증권/종목 분석 서비스 | 대출 계산기 | 금융교육 콘텐츠 | 본 서비스 |
|---|---|---|---|---|
| 과거 종목 위험 지표 | 확인 필요 | 해당 없음 | 제한적 | 제공 |
| 개인 재무상태 반영 | 확인 필요 | 대출 중심 | 제한적 | 제공 |
| 개인×종목 손실 결합 | 확인 필요 | 해당 없음 | 확인 필요 | 핵심 기능 |
| 생활비·비상자금 영향 | 확인 필요 | 확인 필요 | 설명 중심 | 수치 제공 |
| 매매 추천 없음 | 서비스별 확인 | 해당 없음 | 대체로 없음 | 명시적 원칙 |

서비스명, 확인일, URL, 화면 캡처를 증빙으로 보관한다. 차별점은 경쟁 서비스에 실제로 없는지 검증한 뒤 확정한다.

2026-11-02 상세기획서 초안에서는 Investor.gov의 복리 계산기, KB국민은행의 상환 방식 안내, TradingView의 과거 차트 재생을 공식 자료에서 확인했다. 이를 참고 기능으로 비교하며 페이지에 없는 기능이 해당 서비스 전체에서 미지원이라고 단정하지 않는다. 출처와 확인 범위는 [본문 초안](contest/리스크렌즈_상세기획서_초안.md)에 기록했다.

## 4. 민관협력 지원 플랫폼 활용 계획

현재 배포 서버는 팀이 개인 계정으로 개설한 Naver Cloud에 있다. 공모전 지원 플랫폼이 제공한 계정이나 승인된 자원을 사용한 것은 아니다. 신청·승인 없는 자원을 플랫폼 활용 실적으로 과장하지 않고, 상세기획서에는 실제 클라우드 사용과 공모전 지원 플랫폼 이용 범위를 구분한다. 개인 계정 사용이 플랫폼 활용으로 인정되는지는 운영사무국에 확인할 필요가 있다.

| 구성 | 현재 적용 내용 |
|---|---|
| Compute | Naver Cloud Ubuntu 24.04 Micro 서버 1대 |
| Network | VPC, Public Subnet, 공인 IP, ACG |
| API 운영 | Nginx reverse proxy + Uvicorn/systemd |
| 보안 | DuckDNS 도메인, HTTPS, 서버 환경변수로 secret 분리 |
| 상태 확인 | 공개 `/health` endpoint와 Android 앱 연결 상태 UI |

운영 주소는 `https://service-contest-2026-api.duckdns.org`다. 서버에는 FastAPI와 외부 LLM API secret만 배치하며 데이터베이스와 복잡한 인프라는 추가하지 않는다. 신청서에는 클라우드 콘솔·HTTPS 상태 화면과 단일 서버 아키텍처를 근거로 넣는다.

2026-11-02 최신 API를 전체 버전 배포했으며 공개 시세 provider는 disabled다. 운영 현금흐름·AI 가상 문제 응답과 실제 시세 차단을 확인했다. 공개 자료에는 오프라인 체험의 독립 가상 그래프·문제를 사용하고 실제 시세에서 계산한 값을 복사하지 않는다. 가상 조작 영상 `output/demo/RiskLens-cash-flow-walkthrough.mp4`는 약 2분 37초의 무음 자료다.

## 5. 외부 협력 계획

외부 협력은 현재 구현 완료 기능이 아니라 제출 이후 검증 계획이다. 확정되지 않은 기관이나 전문가를 협력 완료로 쓰지 않는다. 모집 가능한 사용자와 학교 지도체계부터 작은 검증을 수행하고, 섭외된 대상만 증빙한다.

| 대상 | 요청 내용 | 남길 증빙 |
|---|---|---|
| 금융 지식 보유자/지도교수 | 계산식, 지표 정의, 오해 가능 문구 검토 | 검토표와 반영 내역 |
| 법률·규제 자문 가능자 | 투자 자문 오인, 개인정보, 면책 표현 검토 | 질의·답변과 수정 내역 |
| 목표 사용자 5명 이상 | 입력 난이도, 결과 이해도, 행동 권고로 오인하는지 확인 | 익명 테스트 기록 |
| 공모전 멘토 | 사회현안 적합성, 제공 플랫폼 활용 방식 검토 | 멘토링 피드백 |

개인정보가 포함된 인터뷰 원본은 제출 자료에 넣지 않고 익명화된 요약과 개선 전후만 사용한다.

이전 Naver Finance 시세는 개발 기록으로만 남긴다. 현재 로컬 소스의 미국 상장 주식·ETF 시세 제공자는 Twelve Data이며 공공데이터나 민관협력 플랫폼 제공 데이터로 표현하지 않는다. 비공개 심사 시연에는 Basic 이용 범위를 지키고, 공개될 수 있는 발표 PDF에는 Twelve Data 실데이터 및 파생 결과 대신 명시적인 가상 예시를 사용한다. Naver Cloud 인프라 활용과 외부 시세 활용 실적을 구분한다.

## 8. 상세기획서 작성본과 초안

2026-11-02 공식 서비스 개발 양식의 일곱 항목을 확인하고 내용 초안과 검토용 7쪽 PDF를 작성했다. 현재 공식 다운로드 HWP는 이전에 확보한 원본과 바이트 해시가 같다. 바탕화면의 `.doc` 및 원본 HWP는 수정하지 않았다. 실제 시세에서 유래하지 않은 가상 화면 두 장·직접 계산한 가상 현금흐름·구성도를 포함했다. 개인 계정 Naver Cloud 사용, 공모전 발급 자원 미사용, 외부 협약·사용자 조사 미실시, 공개 시세 제한을 사실대로 구분했다.

- 편집할 본문: [항목별 Markdown](contest/리스크렌즈_상세기획서_초안.md)
- 검토할 파일: [7쪽 PDF](../output/pdf/리스크렌즈_상세기획서_초안.pdf)
- 재생성: `python scripts/build-contest-proposal.py` (Windows 맑은 고딕 사용)

PDF 전용 `reportlab`·`pypdf`는 `tmp/proposal-tools`에 설치했다. 앱·API 배포 의존성을 바꾸지 않는다.

사용자가 제공한 원본 Word 양식의 일곱 제목, 표, 본문 15pt와 페이지 설정을 유지해 별도의 9쪽 작성본을 만들었다. 두 가상 화면과 세 환경으로 나눈 구성도를 포함하며, 출처에는 클릭 가능한 원문 링크를 넣었다. 원본의 작성 안내문을 실제 내용으로 바꾸고 안내용 원형 글머리표의 내어쓰기를 새 서술 문단에 맞게 정리했다. 원본 SHA-256은 작업 전후 같다. 네이티브 Word 인쇄 렌더로 모든 페이지를 확인했으며 DOC와 DOCX는 페이지 수·본문이 같다. 자세한 확인은 [양식 검토 기록](../output/qa/2026-11-02/proposal-form-review.md)에 남겼다.

- 현재 검토할 파일: [작성본 DOC](../output/documents/리스크렌즈_상세기획서_작성본.doc), [작성본 DOCX](../output/documents/리스크렌즈_상세기획서_작성본.docx)
- 현재 양식용 내용: [양식 본문 Markdown](contest/리스크렌즈_상세기획서_양식본문.md)

사용자 내용 검토와 홈페이지 제출은 별도 단계이며, 제출 완료로 기록하지 않는다.

## 9. 공개·심사 참고자료 제작

2026-11-02 [참고자료 구성](contest/리스크렌즈_참고자료_구성.md)에 따라 공개 PDF 7쪽, 심사용 PDF 6쪽, 메일 증빙 안내서 6쪽과 각각 73초 시연 영상을 제작했다. 화면은 새로 촬영한 Android 1.2.0의 최종 편집 영상에서 추출했다. 공개용에는 독립된 가상 사례만 사용한다. 심사용에는 계산 결과·출처·기준일과 실제 일별 종가를 시작값 100으로 맞춘 가격 차트를 포함한다. 원시 API 응답·인증정보·다운로드 가능한 시세 데이터는 포함하지 않는다.

문의 당시 차트 미표시 계획과 이번 보충 시연의 차이는 안내서에 기록했다. 회신은 비공개 시연과 공개 자료의 이용 범위를 구분한 근거로 사용하며, 차트까지 별도로 명시 승인한 증거라고 표현하지 않는다.

향후 계획은 외부 표시가 허용되는 사업자 플랜과 필요한 이용 권한 확보를 조건으로 작성했다. 개인용 Pro 결제만으로 배포가 자동 허용된다고 쓰지 않았다. 내부용 자료의 공개 제외 문구는 주최 측에 대한 요청이며 수락이 확정된 것으로 기록하지 않는다. ZIP은 준비했으며 홈페이지 제출은 하지 않았다.
