## 2. 사회문제 정의와 근거

핵심 문제는 차입투자자가 가격 하락과 이자 부담을 동시에 감당해야 하지만, 일반적인 종목 정보만으로 그 충격을 자기 생활비와 비상자금 단위에서 이해하기 어렵다는 점이다.

| 근거 | 공식 자료와 기준 | 해석의 한계 |
|---|---|---|
| 부채 상환 부담으로 소비가 제약된 가구 | 한국은행은 2025년 부채 보유 가구의 11.1%를 상환 부담에 따른 소비 제약 가구로 추정했다. 저소득층 비중은 2021년 11.4%에서 2025년 14.5%로 늘었다. <https://www.bok.or.kr/imer/bbs/B0000514/view.do?depth=500835&menuNo=500835&nttId=11064528> | 전체 가계부채 분석이며 주식 차입투자만을 뜻하지 않는다. |
| 청년 금융이해력과 진단 접근성 | 금융위원회는 2024년 금융이해력 조사에서 20대가 62.6점, 전체 성인이 65.7점이었다고 밝혔다. 2025년 기존 청년 상담은 약 4,600명에게 제공됐다. <https://www.fsc.go.kr/po010106/87218> | 낮은 점수가 곧 차입투자를 의미하지 않는다. 맞춤 진단의 필요성을 보조한다. |
| 가계부채 규모 | 통계청의 2025년 가계금융복지조사에서 가구당 평균 부채는 9,534만 원으로 전년 대비 4.4% 증가했다. <https://www.kostat.go.kr/board.es?act=view&bid=215&list_no=439535&mainXml=Y&mid=b80501010000> | 가구 평균이며 개인별 위험이나 투자 목적 부채를 나타내지 않는다. |
| 주식시장 레버리지 위험 | 한국은행 금융안정보고서는 차입을 통한 주식투자 확대가 시장 변동성과 금융불균형을 키울 수 있다고 지적했다. <https://www.bok.or.kr/portal/bbs/B0000502/view.do?depth=201265&menuNo=201265&nttId=11062194> | 시장 전체 위험에 대한 진단이며 개인 손실을 예측하는 자료가 아니다. |
| 신용거래의 개인 위험 | 금융투자협회 안내는 신용거래 시 상환 능력, 다른 지출, 이자와 반대매매 위험을 함께 고려해야 한다고 설명한다. <https://law.kofia.or.kr/service/law/lawFullScreenContent.do?historySeq=1464&seq=281> | 교육 자료이며 개인별 정량 분석 도구는 아니다. |

이 자료는 서비스 필요성을 설명하는 데만 사용한다. 특정 연령이나 부채 보유자를 위험하다고 단정하지 않는다.

## 3. 기존 서비스와 차별점

2026년 9월 28일 공개 페이지 기준의 비교다. 제출 전 실제 화면과 이용약관을 다시 확인하고 캡처를 보관한다.

| 비교 대상 | 공개적으로 확인한 역할 | 본 서비스와의 차이 |
|---|---|---|
| Npay 증권 <https://stock.naver.com/> | 종목 시세와 시장 정보 제공 | 공개 화면에서 개인 재무상태와 종목 하락폭을 결합한 생활 충격 분석은 확인하지 못했다. |
| 금융위원회 청년 금융상담 | 소득·지출·부채 기반 기초 진단과 상담 연계 | 특정 종목의 과거 하락 위험을 투자 예정금액에 적용하는 기능은 공개 설명에 없다. |
| 금융투자협회 신용거래 안내 | 이자, 상환 능력, 반대매매 등 위험 안내 | 정성적 경고를 개인의 생활비·비상자금 기준 수치로 변환하지 않는다. |
| 본 서비스 | 과거 종목 위험과 개인 재무상태를 결합한 가정형 충격 분석 | 투자 추천이나 미래 예측 없이 예상 손실, 자기자본 영향, 이자, 생활비 영향을 함께 제시한다. |

차별점은 “위험한 종목 판정”이 아니라 “같은 하락이 발생할 때 현재 사용자가 받는 충격의 크기”를 결정론적 계산으로 보여주는 데 있다.

## 4. 민관협력 플랫폼 활용 실적

MVP API는 Naver Cloud Platform에 실제 배포했다.

- Ubuntu VM 1대에서 FastAPI를 systemd 서비스로 운영
- Nginx 리버스 프록시와 Let's Encrypt HTTPS 적용
- DuckDNS 도메인 `service-contest-2026-api.duckdns.org` 연결
- ACG에서 HTTP, HTTPS, 제한된 SSH만 허용
- OpenAI 키는 서버의 권한 제한 환경파일에만 저장
- DB, 로그인, 컨테이너 오케스트레이션은 MVP에서 제외

단일 VM 구조는 4인 학생 팀이 직접 이해하고 장애를 확인할 수 있으며, 공모전 시연에 필요한 공개 API와 HTTPS를 가장 작은 운영 범위로 제공한다. 증빙은 NCP 서버·ACG 화면, HTTPS `/health` 결과와 [실기기 연결 화면](assets/app-home-cloud.png)을 사용한다. IP, 이메일, 토큰, 인증키는 캡처에서 가린다.

## 5. 외부 협력과 사용자 검증

| 대상 | 요청 내용 | 남길 증빙 |
|---|---|---|
| 금융 지식 보유자 또는 지도교수 | 계산식, 지표 정의, 오해 가능 문구 검토 | 검토표와 반영 내역 |
| 법률·규제 자문 가능자 | 투자 자문 오인, 개인정보, 면책 표현 검토 | 질의·답변과 수정 내역 |
| 목표 사용자 5명 이상 | 입력 난이도, 결과 이해도, 행동 권고 오인 여부 확인 | 익명 테스트 기록 |
| 공모전 멘토 | 사회현안 적합성과 플랫폼 활용 방식 검토 | 멘토링 피드백 |

검증 지표는 3분 내 흐름 완료율, 입력 오류 필드, MDD·회복 필요 상승률 설명 성공률, 투자 추천 오인 수, AI 설명 전후 이해도다. 개인정보가 있는 원본은 제출하지 않고 익명 요약과 개선 전후만 남긴다.
