## 제출 파일

제출할 때는 바탕화면 `공모전 용` 폴더에서 다음 두 파일만 선택한다.

| 그 외 참고자료(선택) | `리스크렌즈_참고자료_제출용.zip` |

상세기획서 제작본은 10쪽이며 저장소의 [작성본 DOCX](../../output/documents/리스크렌즈_상세기획서_작성본.docx)·DOC를 바탕화면에 `수정본` 이름으로 복사했다. 기존 열린 작성본을 보존하기 위해 바탕화면에서만 새 이름을 사용했다. 7쪽 PDF 초안과 원본 양식은 최종 상세기획서가 아니다. ZIP은 약 17.5 MB로 화면에 안내된 200 MB 한도 이내다. 폴더 전체를 압축하거나 키 메모·PEM·서명 백업·APK를 추가하지 않는다.

2026-11-03 최초 파일 검사에서는 바탕화면 DOCX가 저장소 제작본과 달랐다. 후속 AI 역할 문구 수정은 이 바탕화면 DOCX를 기준으로 수행해 사용자의 추가 편집을 보존했다. 표와 본문 두 곳만 고친 뒤 DOC도 같은 내용으로 저장했고, 현재 바탕화면 수정본과 저장소 제작본의 해시는 일치한다. 두 형식 모두 10쪽이며 Word 인쇄 렌더의 모든 페이지가 픽셀 단위로 일치함을 확인했다.

바탕화면 ZIP은 사용자가 삭제 후 복구한 파일이며 안내서와 SHA-256 목록이 저장소의 이전 생성본과 달랐다. 후속 수정은 복구본을 기준으로 공개 PDF와 해시 목록만 교체했다. 안내서·심사용 PDF·영상·메일 PNG·읽기 안내는 원본 바이트를 유지했다. 현재 저장소 `output/submission`과 바탕화면 ZIP은 같은 수정본으로 동기화했다. 9개 항목의 CRC와 해시 목록 전체를 검사했다.

## 공개용·심사용 구분 근거

실제 문의는 이름·심볼·관측 기간·출처·계산 결과를 보여 주고 원시 일별 가격·가격 차트·API 응답은 표시하지 않는 조건으로 작성됐다. 답장은 Basic 및 개인 플랜의 비공개 심사 영상을 일반적으로 내부/비공개 이용으로 설명하고, 실제 데이터에서 계산한 결과를 담은 공개 다운로드 PDF는 외부 표시로 구분했다.

이번 보충 심사 영상과 PDF에는 실제 일별 종가를 첫 관측값 100으로 맞춘 원화·달러 비교 차트를 추가했다. 비공개 교육 시연이라는 회신 취지와 내부 이용 안내를 종합한 처리이며, 회신이 차트 항목까지 별도로 명시 승인한 증거라고 표현하지 않는다. 원시 API 응답·인증정보·다운로드 가능한 가격 데이터는 넣지 않았다. 공개 자료의 가상 그래프·지표·수치는 Twelve Data 실제 데이터에서 변형하거나 추출한 값이 아니다. 실제 시세 파생 결과·메일 캡처를 담은 심사 자료와 전체 ZIP은 Git에서 제외한다.

비공개 표시는 주최 측에 전달하는 처리 요청이다. 파일명만으로 공모전 공표 조건이 변경되거나 비공개 처리가 수락됐다고 기록하지 않는다.

- 심사용: 가상 재무 입력과 실제 AAPL 계산 결과·일별 종가 기반 차트를 로컬 API로 연결했다. 제공자의 공개 demo 인증 방식으로 촬영했으며 사용자 secret을 읽거나 앱에 넣지 않았다. 차트 시점 선택과 MDD 구간도 확인했다. 원시 응답·인증정보는 촬영하지 않았다.
- 이번 심사 촬영은 `LLM_PROVIDER=template`이다. `검증된 기본 설명`을 실제 LLM 생성 응답으로 표현하지 않는다. 기존 AI 검증과 이번 영상의 범위를 구분한다.

## AI 역할 문구 수정

2026-11-03 구현과 대조해 AI 역할 설명을 바로잡았다. 실제로는 서버가 8개 주제 중 5개와 수치·선택지·정답을 결정하며, AI는 제목·도입 문구만 작성한다. 인터넷 없는 체험에는 준비된 문제를 사용한다. 이 구분은 공개 자료에서 AI 사용이 금지된다는 뜻이 아니다.

사용자의 후속 요청에 따라 Word의 활용 자원 표·AI 역할 본문과 공개 PDF 5쪽 하단에 이 설명을 반영했다. Word 10쪽과 공개 PDF 7쪽을 렌더해 확인했고, 공개 PDF의 나머지 6쪽은 기존 페이지와 픽셀이 같다. 첨부 MP4와 ZIP의 별도 영상도 해시가 일치한다. 현재 양식 본문·Word·공개 PDF에 AI 주제 선택 보조라는 잘못된 설명은 남기지 않았다.

로컬 촬영 원본·타임스탬프·캡처가 있는 `tmp/submission`이 필요하다.
