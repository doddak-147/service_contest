# 리스크 렌즈 상세기획서

**작품명:** 리스크 렌즈 차입투자와 생활 충격을 확인하는 금융위험 예방 서비스  
**팀명:** 리스크 렌즈  
**팀 구성:** 조장 이도윤 · 팀원 장효재 · 팀원 이혁  
**작성 기준:** 2026년 11월 2일 · Android 앱 1.2.0

## 추진배경 및 목적

### 손실률을 자신의 생활 조건에 적용하는 데서 출발

차입투자를 검토하는 사람에게 주가의 하락률과 대출의 연이율은 각각 주어지는 정보다. 그러나 투자자산이 줄어들어도 차입 원금은 남으며, 소득이 줄거나 생활비가 늘어나는 동안에도 이자와 상환금은 현금으로 지출된다. 개인은 이 정보를 자신의 자기자본·비상자금·월 생활비와 연결해 해석해야 한다.

한국은행·금융감독원의 「2024 전국민 금융이해력 조사」는 만 18~79세 성인 2,400명을 대상으로 했다. 금융지식은 73.6점, 금융행위는 64.7점이었다.[2] 서로 다른 평가 영역의 점수이므로 단순한 격차만으로 원인을 단정할 수는 없지만, 지식을 생활 속 적용으로 연결하는 교육 도구를 설계할 근거로 참고했다. 이 조사는 차입투자자의 피해 규모나 본 서비스의 예방 효과를 측정한 자료는 아니다.

### 예방 서비스의 목적

리스크 렌즈는 거래 이전에 사용자가 손실·이자·생활 충격을 자신의 금액 단위로 확인하도록 돕는다. 가정에 따른 계산 결과를 설명하며, 투자 추천·매수/매도 판단·투자 가능 여부 판정·미래 가격 예측은 제공하지 않는다. 우선 대상은 차입투자를 검토하거나 위험 개념을 익히려는 대학생·사회초년생과 초보 투자자다. 특정 연령층이 일률적으로 위험하다고 판정하지 않는다.

### 해결하고자 하는 세 가지 이해 과제

- 같은 하락률이라도 차입 비중에 따라 자기자본 대비 충격이 달라진다는 점을 확인한다.
- 투자자산의 평가손실과 실제로 지급하는 이자·원금·생활비를 구분한다.
- 소득·생활비·금리 가정을 바꾸고 월별 현금 여력이 어떻게 달라지는지 비교한다.

이를 위해 개인 금융체력, 과거 위험, 고정 충격, 월별 현금흐름, 짧은 이해 체험을 한 앱에 연결했다. 과거 성과는 미래 결과를 보장하지 않으며, 제공 범위와 계산 가정을 결과에 표시한다.

## 개요

리스크 렌즈는 재무 입력과 위험 가정을 받아 손실의 금액 규모, 자기자본·비상자금·생활비 대비 영향, 월별 현금 잔액을 보여주는 Android 앱이다. 로그인 없이 사용하며 분석 이력을 서버에 저장하지 않는다. 사용자는 가정을 직접 조절하고 두 조건의 결과를 화면 안에서 비교한다.

## 개발 환경 구성

### 모바일과 단일 계산 서버

Flutter·Dart Android 앱이 HTTPS/JSON으로 FastAPI·Python 계산 서버를 호출한다. Naver Cloud의 Ubuntu 24.04 서버에서 Nginx가 TLS를 처리하고 localhost의 Uvicorn에 전달한다. systemd가 서비스를 관리한다. 로그인·데이터베이스·서버 분석 이력은 두지 않는다.

### 기능별 구성과 입력 경계

financial-health는 개인 재무 지표, market-risk는 시세·환율과 과거 위험, stress-test는 충격·현금흐름, combined-report는 개인과 종목의 결과 조합을 담당한다. foundation은 서버 상태와 가상 문제 구성을 제공한다. 모바일·서버는 같은 API 계약의 필드명과 자료형을 사용한다.

금액은 정수 원 또는 Decimal로 계산한다. 계산 함수와 외부 통신을 분리해 같은 입력·같은 시계열에서 같은 결과를 얻는다. 계산할 수 없는 비율은 0으로 대체하지 않고 사유와 함께 표시한다. A/B 입력·결과 쌍은 화면 메모리에만 보관하고 화면 종료 시 폐기한다.

### 운영과 개인정보 처리

재무 원본과 인증정보를 요청 로그에 남기지 않는다. API 키는 서버 환경변수에만 두며 앱·Git에 포함하지 않는다. LLM에는 이름·원본 재무 목록·인증정보를 보내지 않는다. 현금흐름 결과를 LLM에 추가 전송하지 않으며 퀴즈 모델에는 고정된 주제명만 보낸다.

서버 갱신은 새 버전을 별도 경로의 임시 서비스에서 검사한 뒤 전환하고 실패 시 기존 설정을 복원하도록 구성했다. 공개 운영 실행에서는 시세 provider를 비활성화하고 Nginx 차단을 함께 유지한다. Android 서명 파일은 암호화 백업·실제 복원·외부 백업 다운로드 일치 검사를 마쳤다.

## 내용

### 개인 재무와 과거 위험의 계산

월 잉여현금은 소득에서 고정지출과 기존 월상환액을 뺀 값이다. 비상자금 버팀 개월은 비상자금을 고정지출·기존 월상환액 합으로 나눈다. 투자용 월 이자는 차입금과 연이율로 계산한다. 이 지표를 하나의 투자 적합성 점수로 합치지 않는다.

비공개 시세 분석은 Twelve Data의 분할 조정·배당 제외 USD 종가와 같은 날 또는 5일 이내 직전 ECB 참고 환율을 결합한다. 참고 환율은 실제 환전가가 아니다.[6] 관측 범위의 수익률, 일간 수익률의 표본 표준편차에 기반한 연환산 변동성, 누적 고점 대비 최대 하락률을 계산한다. 부족한 관측이나 누락 환율을 임의로 추정하지 않는다.

### 손실과 회복의 관계

- MDD = 관측일별 (원화 가격 / 해당 일까지의 최고 원화 가격 - 1)의 최솟값.
- 고정 주가·환율 충격 = (1 + 주가 변화율) × (1 + 원/달러 환율 변화율) - 1.
- 하락 후 투자자산 = 투자금 × (1 + 가정 수익률). 순투자지분은 여기서 투자용 차입 원금을 뺀다.
- 손실률 L의 회복 필요 상승률 = L / (1 - L). 100% 손실에는 유한한 회복률이 없다.

원화 기준 과거 MDD에는 이미 환율이 반영되어 있으므로 환율 충격을 중복 적용하지 않는다. 가격 그래프는 첫 관측값을 100으로 맞춘 원화·달러 흐름이며 명목 주가나 미래 예측선이 아니다.

### 가상 현금흐름 예시

모든 아래 값은 실제 시세에서 유래하지 않은 독립 가상값이다. 월 소득 300만 원, 생활비 150만 원, 기존 월상환 40만 원, 시작 비상자금 500만 원, 자기자본 600만 원, 투자용 차입 400만 원, 연이율 6%를 가정한다. 투자용 원금 만기는 36개월이며 그전에는 이자만 납부한다.

생활 충격은 소득 -20%, 생활비 +10%, 투자용 금리 +2%p다. 첫 달 이자는 20,000원에서 26,667원, 월 현금수지는 1,080,000원에서 323,333원으로 바뀐다. 이자 자체가 기간에 비례해 증가하는 것이 아니라 납부한 이자가 누적된다.

| 기간 | 기본 조건 말일 현금 | 충격 조건 말일 현금 | 충격 조건 누적 이자 |
| --- | --- | --- | --- |
| 3개월 | 8,240,000원 | 5,969,999원 | 80,001원 |
| 6개월 | 11,480,000원 | 6,939,998원 | 160,002원 |
| 12개월 | 17,960,000원 | 8,879,996원 | 320,004원 |

월별 소득·지출·이자·원금은 원 단위 반올림한 뒤 합산한다. 투자 평가손실은 위 현금에서 차감하지 않으며 매도·배당 수입은 가정하지 않는다. 음수 잔액은 자금 부족분이며 추가 차입이나 연체이자를 자동 생성하지 않는다.

### 이용자 시나리오와 구현 화면

운영 앱 사용자는 재무값을 입력해 금융체력을 보고, 고정 가격 충격이나 월별 현금흐름을 선택한다. 기간·상환 방식·생활 충격을 정한 뒤 계산 결과를 A에 보관하고 조건을 바꿔 B와 비교한다. 이후 이해 체험의 5문제를 풀며 정답·오답과 계산 근거를 확인한다.

비공개 심사 시연에서는 미국 주식·ETF를 검색하고 원화 기준 과거 위험을 조회한 뒤 개인 재무상태와 결합한 영향을 확인한다. 공개 자료용 시연은 별도 오프라인 체험을 사용한다. 아래 두 화면은 명시된 독립 가상값이며 실제 시세·실데이터 파생 결과를 포함하지 않는다.

### AI의 역할과 대체 흐름

쉬운 설명은 서버가 이미 계산한 최소 결과를 바탕으로 생성하고 새 숫자·투자 권고 표현 등을 검사한다. 문제 생성에서는 수치·선택지·정답·계산식을 서버가 확정하고 AI는 제목·도입만 작성한다. AI 설정·통신·문구 검증에 실패하면 기본 설명이나 자체 문제를 표시한다. 정답 확인 후 선택은 고정되며 풀이 기록을 서버에 보내지 않는다.

### 확인한 완성도와 남은 검증

계산·API·어댑터의 회귀 테스트와 Flutter 테스트 81개, 이후 배포·검사 스크립트 테스트 21개를 해당 변경 시점에 통과했다. Android 16 기기에서 운영 연결 검사 4종을 확인했고, AI는 한 차례 자체 문제 대체 뒤 재요청에서 성공했다. 사용자는 USB 분리 후 3개월·6개월 현금흐름도 확인했다. 별도의 외부 사용자 조사·만족도 측정·금융 전문가 검토는 아직 수행하지 않았다.

## 기대효과

### 개인과 금융교육 현장의 활용

개인은 같은 손실률을 자기자본·비상자금·생활비 단위로 바꿔 살펴보고, 소득·지출·금리 변화가 월별 현금 여력에 미치는 영향을 구분할 수 있다. 교육자는 완전 가상 사례와 계산 근거를 활용해 차입·회복률·환율·현금흐름을 설명할 수 있다. 로그인 없는 구조와 API 무호출 체험은 개인정보 입력이나 실데이터 계약 없이 교육용 사례를 확인할 수 있게 한다.

이는 기대하는 활용 효과다. 서비스 이용으로 실제 손실·연체가 줄었다거나 금융이해력이 향상됐다는 성과는 아직 측정하지 않았다. 특정 투자 행동이나 대출 선택을 권고하는 수단으로 사용하지 않는다.

### 향후 효과 검증 계획

| 확인할 지표 | 측정 방법 |
| --- | --- |
| 결과 이해 | 평가손실과 현금 지출을 사용자가 자신의 말로 구분하는지 확인 |
| 개념 적용 | 가상 회복률·월 이자·환율 문제의 체험 전후 설명을 비교 |
| 사용성 | 입력 오류·중도 이탈·과제 완료 시간을 동의하에 익명 기록 |
| 오해 가능성 | 결과를 투자 추천·안전 판정으로 받아들이는지 면담 |

참여에 동의한 대상과 절차를 정한 뒤 측정하며 예상 수치를 실적으로 제시하지 않는다. 이후 우선 보완은 실제 데이터의 이용 권한·접근 통제 확인, 참여 가능한 교육 주체와의 표현 검토, 사용자 과제 기반 개선이다.
