# 주가 데이터 검증 기준

## 목적

종목 위험 계산이 외부 제공자의 비정상·중복 데이터나 기업행사로 인해 과장되지 않는지 확인한다. 이 문서는 API 계약을 변경하지 않으며 `adjusted_close` 입력과 MDD 검산 기준을 기록한다.

## 자동 검증

- 요청 기간 밖의 관측치는 계산에서 제외한다.
- Twelve Data 어댑터는 미국 주식만 받고 날짜별 분할 조정 종가를 하나로 정규화해 날짜순으로 반환한다. 네이버 어댑터의 과거 검증 기록은 회귀 자료로만 남긴다.
- 유한하지 않거나 음수인 가격은 제공자 오류로 처리한다.
- 관측치가 2개 미만이면 수익률·변동성·MDD를 추정하지 않고 `INSUFFICIENT_PRICE_DATA`를 반환한다.
- 100% 손실을 검증하기 위해 0원 가격은 계산 계층에서 허용하되, 실제 제공자 데이터에서는 별도 이상 여부를 확인한다.

## 독립 검산 사례

기준 배열 `10,000 → 12,000 → 9,000 → 8,000 → 11,000`의 결과는 다음과 같다.

- 기간 수익률: `11,000 / 10,000 - 1 = 10%`
- MDD: `(8,000 - 12,000) / 12,000 = -33.3333%`
- 고점일과 저점일: 두 번째 관측일, 네 번째 관측일
- 종료 가격이 12,000 미만이므로 해당 기간에는 전고점 미회복

액면분할 회귀 사례는 삼성전자 50:1 분할 전후인 2018-04-30~2018-05-08의 조정 기준 가격 `53,000 → 53,000 → 51,900 → 52,600`을 고정 fixture로 사용한다. 이 구간의 MDD는 약 `-2.0755%`이며 분할 자체가 `-98%` 수준의 허위 낙폭을 만들면 테스트가 실패한다.

## 실제 제공자 점검

2026-09-18 개발 환경에서 `005930` 검색과 최근 30일 시세 23개를 조회했다. 삼성전자 2018년 50:1 분할 구간과 카카오 2021년 5:1 분할 구간도 조회해 분할 전후 가격이 동일한 조정 기준으로 반환되고, 각각의 구간 MDD가 약 `-3.9623%`, `-2.4896%`로 계산되는 것을 확인했다. 이 실통신 확인은 CI에 넣지 않고 제출 전 같은 종목·구간으로 다시 점검한다.

2026-09-29에는 Naver Cloud 운영 API와 Android 실기기를 연결해 종목 검색, 1·3·5년 기간 변경, 기간 수익률·연환산 변동성·MDD·회복일 표시와 결합 Report 이동을 확인했다. 이 확인은 통신과 화면 흐름 검증이며 다른 제공자와의 수치 대조를 대신하지 않는다.

## 한계와 제출 전 확인

아래 2026-10-10까지의 네이버 금융 실통신 결과는 과거 개발 기록이며 현재 선택한 데이터 제공자의 검증 결과가 아니다. 현재 결과를 배당 포함 총수익률이나 미래 손실 확률로 해석하면 안 된다. 제출 전에는 다음을 다시 확인한다.

2026-10-10 로컬 개발 환경에서는 `AAPL` 검색과 최근 약 3개월의 미국 일별 시세 71개를 네이버에서 조회하고, ECB 일별 EUR 대비 USD·KRW 기준값을 날짜별로 맞춰 KRW 가격을 생성했다. 이는 연동 점검이며 조정종가 또는 투자자가 실제 체결하는 환율임을 증명하지 않는다. 미국 시세의 기업행사 조정 여부와 데이터 사용 조건을 별도로 확인해야 한다. ECB 기준값은 휴일·시차에 따라 주가일보다 최대 5일 앞설 수 있으며 그보다 오래된 환율만 있는 날은 제외한다. GitHub Actions의 평일 점검은 소스 가용성 감시일 뿐 환율 데이터 저장·배포 경로가 아니다.

2026-10-12 로컬 소스는 Twelve Data Basic 미국 주식 일별 시세(`adjust=splits`, 배당 제외)로 전환했다. MockTransport unit 테스트를 통과했고, 공개 `demo` 키로 `Apple` 검색과 2024-01-02~2024-01-05의 `AAPL` 일별 시세·ECB 결합(관측치 3개)을 확인했다. 개인 API 키로 현재 기간을 조회하거나 실기기를 검증한 것은 아니다. Basic의 비공개 심사 시연은 Twelve Data 측 이메일 답변에 따르며 공개 PDF에는 실제 시세와 파생 계산값을 사용하지 않는다. 외부 접근 가능한 운영 API에는 접근 제한 전까지 배포하지 않는다.

1. 분할·병합 이력이 있는 종목 2개 이상의 MDD를 다른 공개 데이터와 대조한다.
2. 최신 거래일, 휴장일, 관측치 수와 기준일을 실제 화면에서 확인한다.
3. 제공자 장애 시 금융체력과 고정 시나리오만 남는지 실제 기기에서 확인한다.
