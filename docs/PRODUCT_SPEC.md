# 제품 요구사항 명세

## 1. 제품 정의

`리스크 렌즈(Risk Lens)`는 사용자가 차입금을 포함해 주식에 투자하기 전에, 자신의 금융상태가 가정된 손실에서 어떤 영향을 받는지 객관적인 수치로 확인하는 모바일 금융위험 예방 서비스다.

핵심 질문은 **“얼마나 벌 수 있는가?”가 아니라 “얼마나 잃으면 현재의 내 생활과 자기자본에 어떤 충격이 생기는가?”**이다. 종목 추천, 매수·매도 권유, 투자 가능 여부 판정, 미래 주가 예측은 제공하지 않는다.

### 현재 MVP 구현 상태

현재 기준은 2026-11-02의 1.2.0이다. 금융체력·고정 충격·현금흐름/생활 충격·A/B·AI 5문제 API는 Naver Cloud에 배포했고 외부 HTTPS 응답을 검증했다. 미국 주식·ETF의 실제 과거 위험·가격 그래프·결합 Report는 비공개 로컬 시연에서만 제공한다. 공개 운영 시세는 disabled이며 Nginx 차단을 유지한다. 아래 날짜별 내용은 과거 개발 기록이며 최신 제공 범위는 이 문단과 README를 따른다.

#### 이전 개발 기록

2026-09-29 기준으로 개인 금융체력, 고정 가격 충격 Stress Test, 국내 종목 검색·과거 위험, 개인×종목 결합 Report, 제한적 AI 설명과 정적 fallback이 구현되어 있었다. 당시 이후 단계였던 배포 APK·추가 UI는 이후 버전에서 완료했으며 아래 기록을 현재 미구현 목록으로 사용하지 않는다.

2026-10-10 로컬 소스에는 미국 종목 검색, 최근 3개월의 원화 환산 과거 위험, 독립적인 주가·환율 충격 Stress Test를 추가했다. 운영 서버 반영은 아직 별도 작업이다.

2026-10-12 로컬 소스의 실제 시세 연동을 Twelve Data Basic의 미국 주식으로 전환했다. 국내 종목은 제공하지 않으며 운영 서버는 아직 이전 버전이다. 비공개 심사 시연과 공개 제출 자료의 데이터 사용 범위는 구분한다.

2026-10-27 로컬 소스는 미국 상장 ETF도 검색·과거 위험·결합 Report 대상으로 확대했다. `SPY`·`QQQ`는 지수가 아닌 ETF로 구분해 표시한다. 두 ETF의 검색과 과거 위험 결과를 USB 연결 Android 실기기에서 확인했다. 공개 운영 서버 반영은 하지 않았다.

2026-10-27 로컬 모바일 화면은 가상 재무 예시/빈칸 입력을 구분하고, 결합 Report 상단에 손실 충격 요약을 추가했다. Stress Test는 같은 자기자본을 유지한 차입 없음/차입 있음 두 경우를 기존 계산 API로 별도 계산해 보여준다. SPY·QQQ 빠른 선택과 긴 ETF 이름 표시를 개선했다. 이 화면 변경의 실기기 검증과 운영 반영은 아직 하지 않았다.

2026-10-28 로컬 모바일에 공개 자료 캡처용 `오프라인 체험 · 완전 가상`을 추가했다. 실제 종목·Twelve Data 시세 및 파생 지표·환율·AI 응답을 사용하지 않는 고정 사례를 재무/가상 종목/결합 결과 3단계로 보여준다. 이 화면은 서버 요청 없이 작동한다. 기존 `가상 예시로 체험`은 재무 값만 가상이고 실제 시장 데이터가 섞일 수 있으므로 공개 자료에 사용하지 않는다. 실기기 검증과 운영 배포 여부는 별도로 확인한다.

2026-10-30 `SM S906N`(Android 16)에서 로컬 디버그 APK를 덮어 설치해 오프라인 체험의 가상 재무 → 가상 종목 → 결합 결과 이동, 지속 표시되는 가상 데이터 배너, 가상 설명과 상세 영역 펼치기를 확인했다. 실기기 화면에서 잘림·앱 종료·Flutter 예외는 관찰되지 않았다. 서버 503 모의 응답에서도 체험 화면이 API 요청 없이 동작하는 위젯 테스트를 통과했다. 실제 네트워크를 끈 상태와 공개 운영 서버 배포는 이번 검증에 포함하지 않았다.

2026-10-30 로컬 모바일 UI에 기존 계산 결과를 사용하는 시나리오별 손실·순투자지분 금액 막대와 손실 전후 자금 구조 그림을 추가했다. 홈에는 실제 시세 그래프가 아닌 장식용 렌즈 일러스트를 넣었다. 그래프는 API 응답값을 표시하며 새 데이터 조회나 계산 계약 변경은 없다. `SM S906N`(Android 16)에서 디버그 APK를 설치해 홈, 오프라인 체험 결합 Report의 자금 구조와 시나리오 그래프를 확인했다. 로컬 API에 연결한 Stress Test에서도 그래프, 음수 순투자지분 수치와 기존 비교표가 잘림 없이 표시됐다. `flutter analyze`와 모바일 전체 위젯 테스트 63개가 통과했다.

같은 날 클라우드 주소로 빌드한 앱의 Stress Test는 운영 API가 새 선택 필드 `exchange_rate_change_rate`를 `EXTRA_FORBIDDEN`으로 거부해 HTTP 422가 발생했다. 로컬 API에서는 정상 계산됐다. 이 문제는 10월 31일 운영 Stress Test 모듈만 갱신해 해결했다.

2026-10-31 공개 HTTPS에서 기존 Stress Test 요청과 환율 충격·직접 입력 요청이 모두 HTTP 200으로 처리되는 것을 확인했다. 클라우드 연결 `SM S906N` 실기기에서 가상 재무 예시의 `-17.5%` 직접 입력 시 예상 손실 175만 원과 투자 가치 825만 원을 확인했다. 운영 서버의 종목 분석과 Twelve Data 연동은 이번 갱신에 포함하지 않았다.

2026-11-01 공개 운영 API는 Nginx에서 종목 검색·과거 위험·결합 분석 요청에 JSON 503을 반환한다. 금융체력·고정 Stress Test·쉬운 설명 API는 계속 사용할 수 있다. 서명된 Android 설치본에서 종목 검색의 차단 사유와 완전 가상 체험 진입을 확인했다. 실제 미국 시세 기능은 비공개 로컬 시연 범위에만 둔다.

## 2. 대상 사용자와 MVP 성공 기준

- 차입투자를 고민하지만 투자손실과 대출 부담을 함께 계산하기 어려운 개인
- 변동성, MDD, 레버리지 등을 자신의 생활비 단위로 이해하고 싶은 초보 투자자
- 사용자가 3분 안에 입력부터 결합 분석까지 완료한다.
- 사용자가 결과에서 가정, 계산 근거, 과거 데이터의 한계를 설명할 수 있다.
- 수익률이나 거래 전환이 아니라 분석 완료율, 결과 이해도, 시나리오 비교 사용률로 평가한다.

## 3. 핵심 기능

### 3.1 개인 금융체력 분석

월 소득, 월 고정지출, 비상자금, 기존 대출 잔액, 월 대출 상환액, 투자 예정금액, 자기자본, 투자용 차입금, 연 대출금리를 입력받는다. 음수와 단위 오류를 막고 `자기자본 + 투자용 차입금 = 투자 예정금액`을 검증한다.

월 잉여현금, 비상자금 버팀 개월, 차입 비율, 투자용 차입금의 예상 월 이자를 표시한다. 이를 하나의 불투명한 점수로 합치거나 투자 가능 여부를 판정하지 않는다.

홈에서 가상 재무 예시와 내 값 입력을 선택할 수 있다. 내 값 입력은 빈칸으로 시작한다. 예시값으로 시작한 경우 결합 Report에서도 이를 표시하며 실제 시세와 가상 재무값을 혼동하지 않도록 한다.
총 투자 예정금액은 별도로 입력받지 않고 자기자본과 투자용 차입금의 합으로 자동 계산한다. API의 `planned_investment_krw` 필드는 그대로 유지한다.

### 3.2 종목 과거 위험 분석

외부 주가 데이터 API에서 미국 상장 주식·ETF의 분할 조정 일별 종가(배당·분배금 제외)를 조회해 다음을 계산한다. 날짜별 ECB 참고 환율로 원화 환산한 시계열을 사용한다. ETF 가격은 추종 지수 값이나 분배금 재투자 총수익률과 같지 않다. 국내 종목과 지수 자체는 현재 실제 시세 분석 대상이 아니다.

- 기간 수익률: `(종료 조정종가 / 시작 조정종가) - 1`
- 연환산 변동성: 일간 수익률 표준편차 `× √252`
- 최대낙폭(MDD): 누적 고점 대비 가장 큰 하락률
- 주요 하락 구간: 고점일, 저점일, 회복일(있는 경우), 낙폭

데이터 제공자, 조회 기간, 기준일, 관측치 수, 결측 경고를 함께 표시한다. 데이터가 부족하면 값을 추정하지 않는다.
미국 종목은 앱에서 최근 3개월을 조회한다. 환율 기준일, 실제 환전가·수수료와의 차이, 배당을 포함하지 않는다는 한계를 함께 표시한다.

### 3.3 개인 금융상태 × 종목 과거 위험 결합 분석

이 기능이 서비스의 핵심 차별점이다. 종목의 MDD를 단순 표시하지 않고 현재 사용자의 투자 계획에 적용한다.

- 과거 MDD 적용 예상손실 = 투자 예정금액 × `|MDD|`
- 자기자본 대비 손실률 = 예상손실 / 자기자본
- 비상자금 대비 손실률 = 예상손실 / 비상자금
- 생활비 대비 손실 규모 = 예상손실 / 월 고정지출
- MDD 적용 후 투자자산 = 투자 예정금액 - 예상손실
- MDD 적용 후 순투자지분 = 적용 후 투자자산 - 투자용 차입금

결과는 “위험/안전” 판정 대신 “해당 종목의 과거 최대 하락이 반복된다고 가정하면 손실은 자기자본의 72%, 월 고정지출의 8.4개월분”처럼 입력과 근거가 연결된 사실로 표현한다.

### 3.4 Stress Test와 회복 난이도

MVP는 다음 주가 충격 시나리오를 동일 시점에 적용한다.
미국 종목에 한해 원/달러 환율 충격 `-10%`, `0%`, `+10%`를 별도로 가정할 수 있다. 이는 미래 환율 예측이 아니다.

- 상승 `+20%`
- 보합 `0%`
- 하락 `-10%`, `-20%`, `-30%`, `-40%`, `-50%`
- 선택 종목의 과거 MDD
- 사용자가 직접 입력한 가격 변동률 `-100%..+100%` (소수 둘째 자리까지)

각 시나리오에서 투자자산, 투자손익, 자기자본 대비 손실률, 비상자금·생활비 대비 영향, 순투자지분, 기존/투자용 부채, 예상 월 이자를 비교한다. 가격 충격 자체로 대출 원금은 변하지 않는다.

차입 유무 비교는 같은 자기자본·기존 재무조건·시나리오를 사용한다. 차입 없는 기준 사례는 `투자 예정금액 = 자기자본`, `투자용 차입금 = 0`으로 기존 계산 API에 다시 요청한다. 따라서 투자금 규모가 달라지는 비교이며, 어느 선택이 적합한지 판정하지 않는다. 자기자본이 0원이면 차입 없는 기준 사례를 만들지 않는다.

손실률 `L`의 원금 회복 필요 상승률은 `L / (1 - L)`이다. 100% 손실은 유한한 회복률이 없으므로 `계산 불가`와 사유를 표시한다.

### 3.5 월별 현금흐름과 생활 충격

3·6·12개월 동안 소득·고정지출·기존 대출 월상환액·투자용 대출의 이자와 원금 상환을 계산한다. 현금의 시작값은 투자 후 별도로 남겨 둔 비상자금이며 평가손익을 현금에 합산하지 않는다. 소득 감소·지출 증가·투자용 금리 상승을 직접 입력해 충격 전후를 비교한다. 만기 일시 원금 상환 또는 원금 균등분할을 가정하고 월별 현금·누적 이자 그래프와 내역을 표시한다. 음수 현금은 추가 자금 필요액이며 자동 대출을 뜻하지 않는다. 기존 대출 월상환액은 고정하며 기존 잔액의 상환 경로는 추정하지 않는다.

### 3.6 과거 가격 그래프·A/B 비교·이해 체험

과거 위험 조회 후 선택하면 동일 기간 원화·달러 종가를 첫 관측값 100으로 맞춘 그래프와 원화 MDD 고점·저점·회복을 보여준다. 환율 결측을 보간하지 않으며 그래프 오류는 기존 위험 요약을 지우지 않는다. 실제 데이터는 비공개 시연에만 사용한다.

현금흐름의 입력·결과 두 쌍을 가정 A·B로 보관해 차이만 비교한다. 다른 분석 기간은 명시하며 어느 조건이 적합한지 판단하지 않는다. 화면을 닫으면 보관값은 사라진다.

위험 이해 체험은 회복률·환율·복합 충격·누적 이자·현금흐름·평가손실·금리 상승·낙폭의 8개 주제에서 한 번에 5문제를 구성한다. 정답·오답을 색·아이콘·문구로 표시하고 확인 후 정답과 계산 근거를 보여준다. 서버 없이도 자체 문제를 섞어 체험할 수 있다.

홈의 `AI로 새 5문제 만들기`는 주제 선택·가상 수치·정답·선택지를 서버가 결정하고 LLM은 제목·상황 도입 문구만 구성한다. 실제 시세·사용자 재무정보는 사용하지 않는다. AI 문구 검증 실패·서버 장애 시 자체 문제로 이어지며 그 사유를 표시한다. 인터넷 없이 쓰는 가상 체험은 준비된 가상 그래프·현금흐름·자체 문제를 사용하고 서버·AI를 호출하지 않는다. 이는 연결 방식의 차이이며 공개 자료에서 AI 사용을 금지한다는 의미가 아니다.

### 3.7 제한적 AI 설명

모든 계산은 결정론적 Python 코드가 완료한다. LLM에는 이름이나 재무 입력 전체가 아니라 설명에 필요한 최소 파생 결과만 전달한다. LLM은 숫자를 새로 계산하거나 바꾸지 않고 검증된 결과를 쉬운 한국어로 설명한다.

LLM 응답에는 투자 추천과 미래 예측을 허용하지 않는다. 설정이 없거나 실패·검증 거절이 발생하면 사유와 함께 승인된 정적 설명을 표시하며 계산 결과는 그대로 유지한다.

## 4. MVP 범위

포함한다.

- 로그인 없는 재무 입력과 요청 단위 처리
- 단일 종목의 과거 수익률, 변동성, MDD, 주요 하락 구간
- 개인 금융체력과 종목 MDD의 결합 분석
- 고정 가격 충격 8종, 회복 필요 상승률, 결과 비교 Report
- 계산식·데이터 출처·기준일·면책 표시
- 최소 결과만 사용하는 LLM 설명과 정적 fallback
- 3·6·12개월 현금흐름, 상환 방식·누적 이자, 생활 충격 전후·가정 A/B 비교
- 같은 관측 구간의 원화·달러 가격/MDD 그래프(실데이터는 비공개)
- 5문제 이해 체험과 AI 도입 문구, 완전 가상 오프라인 사례
- 핵심 계산 unit test와 주요 사용자 흐름 테스트

제외한다.

- Supabase, PostgreSQL, 회원가입·로그인, 서버 기반 분석 이력
- 포트폴리오, 여러 대출의 개별 상환 방식, 세금·수수료
- 실제 금융상품의 모든 상환 조건과 여러 기존 대출의 개별 잔액 경로
- 가격 예측, 발생 확률, Monte Carlo, 매매 기능, 알림
- 복잡한 분산 인프라와 별도 API 계약 패키지

## 5. 비기능 요구사항

- 같은 입력, 주가 데이터, 계산 버전은 같은 결과를 반환한다.
- 중간 계산은 정수 원 또는 `Decimal` 정밀도를 유지한다. API 응답 직전 금액은 원 단위, 비율은 소수점 6자리로 반올림하고 UI는 표시만 추가 반올림한다.
- 재무 원본, LLM 입력, secret을 로그에 남기지 않는다.
- 결과마다 “교육·위험 인지 목적이며 투자 자문이 아님”과 “과거 성과는 미래 결과를 보장하지 않음”을 표시한다.
- 위험을 색상만으로 전달하지 않고 숫자와 텍스트 레이블을 함께 사용한다.

## 6. MVP 이후

- 실제 대출상품의 상환 조건·수수료 반영은 별도 요구 검증 후 검토
- 복수 종목과 포트폴리오 결합 위험
- 사용자가 명시적으로 동의한 기기 내 결과 저장
- 법률·개인정보 검토 후 계정과 서버 저장 여부 재결정
