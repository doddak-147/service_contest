# 실기기 QA와 사용자 검토

## 2026-10-31 확인 결과

기기: Samsung SM-S906N, Android 16. 검증용 로컬 서버는 실제 시세와 인증정보를 사용하지 않고 503 오류만 반환했다.

| 상황 | 확인 결과 |
| --- | --- |
| 종목 검색 API 503 | 오류 문구가 표시되고 검색 결과를 성공한 것처럼 보여주지 않았다. |
| 종목 위험 API 503 | 오류 문구와 재시도 버튼이 표시되고 이전 위험 수치가 남지 않았다. |
| 서버 종료 후 상태 새로고침 | 홈에 연결 실패와 연결 불가 문구가 표시됐다. |
| 서버 종료 후 오프라인 체험 | 가상 재무, 가상 종목, 결합 결과의 3단계가 완료됐다. 실제 시세·환율·AI 미사용 표시가 유지됐다. |
| 서명된 release APK 설치 | 설치와 실행에 성공했다. USB 포트 전달 없이 운영 HTTPS 서버 연결 및 오프라인 체험 진입을 확인했다. |

자동 검증: `flutter analyze` 이상 없음, `flutter test` 63개 통과. OpenAI 오류 로그의 키·긴 숫자 제거 및 Twelve Data 연결 오류 응답은 API 단위 테스트에서 확인했다. 실제 제공자의 장애, 요청 한도 초과, 운영 서버 로그 내용은 이번 실기기 검증에 포함되지 않았다.

운영 Nginx의 공개 종목 API 차단은 별도 적용 절차가 남아 있다. 이 차단이 검증되기 전에는 APK를 제삼자에게 전달하지 않는다. Twelve Data Basic 사용 범위 밖의 공개 자료에는 오프라인 체험의 명시된 가상값만 쓴다.

## 외부 사용자 검토 절차

팀원이 아닌 5명에게 설치본을 직접 조작하게 하고, 진행자는 처음에 기능을 설명하지 않는다. 실제 재무정보를 입력하거나 화면을 촬영해 공유할 필요가 없도록 오프라인 체험의 가상값만 사용한다. 한 사람당 10~15분으로 진행한다.

1. 첫 화면을 30초 보고 서비스가 무엇을 하는지 한 문장으로 말한다.
2. 오프라인 체험을 시작해 가상 재무 → 종목 → 결합 결과를 끝까지 본다.
3. 손실 그래프와 차입 비교가 무엇을 뜻하는지 자신의 말로 설명한다.
4. 결과가 투자 추천이나 미래 가격 예측으로 읽히는지 말한다.
5. 서버가 연결되지 않을 때 무엇을 할 수 있는지 찾는다.

진행자는 성공 여부, 걸린 시간, 멈춘 화면, 이해하지 못한 표현을 기록한다. 이름이나 개인 재무 수치는 기록하지 않는다. 같은 지점에서 2명 이상 막히거나 투자 권고로 오해하면 우선 수정한다. 수정 후 해당 과업만 다시 확인한다.

## 금융 분야 검토

금융 계산을 검토할 수 있는 외부인 1명에게 가상 예시만 보여주고 다음을 확인받는다.

- 손실액, 자기자본, 차입 원금, 이자 부담의 관계가 맞는가.
- 0인 분모와 100% 손실을 계산 불가 또는 전액 손실로 정확히 설명하는가.
- 과거 최대낙폭과 고정 주가·환율 충격을 구분하는가. 원화 기준 과거 최대낙폭에 환율 충격을 중복 적용하지 않는가.
- 출처, 기준일, 분할 조정, 배당 제외, ECB 참고 환율의 한계가 이해되는가.
- 투자 추천, 매수·매도 판단, 미래 수익 예측처럼 읽히는 문구가 있는가.

검토 의견은 `화면 / 관찰 내용 / 영향 / 수정 제안 / 재확인 결과` 순서로 적는다. 외부 검토는 아직 진행하지 않았으며 의견을 받기 전에는 완료로 표시하지 않는다.
